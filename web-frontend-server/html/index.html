MyMiniCloud – Home

Hệ thống cloud thu nhỏ gồm 9 loại server chạy trong container, kết nối qua mạng cloud-net. Nhóm thực hiện: Đinh Quốc Cường (523H0008) và Nguyễn Cao Hậu (523H0025).

Served by __SERVER_NAME__

Các dịch vụ

1. Web Server

nginx phục vụ trang tĩnh: trang chủ và blog.

2. Application Server

Flask API, gọi qua /api/hello.

3. Database Server

MariaDB lưu dữ liệu ứng dụng.

4. Authentication Server

Keycloak (OIDC), đăng nhập tại /auth/.

5. Object Storage

MinIO, API tương thích Amazon S3.

6. DNS Server

BIND9, zone nội bộ cloud.local.

7. Monitoring

Prometheus và Node Exporter thu thập metric.

8. Visualization

Grafana hiển thị dashboard giám sát.

9. Reverse Proxy / LB

nginx định tuyến theo path và cân bằng tải.

Phần nâng cao

Portal

Đăng nhập Keycloak (PKCE), phân quyền editor/viewer, quản lý sinh viên, ảnh đại diện trên MinIO.

Log tập trung

Loki và Alloy gom log mọi container, tra một request theo request_id trên Grafana.

Giám sát và cảnh báo

cAdvisor theo dõi từng container, Alertmanager gửi cảnh báo về Portal.
