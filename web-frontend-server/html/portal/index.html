MyMiniCloud Portal

Portal là ứng dụng web chạy trong trình duyệt, nối các server của MyMiniCloud thành một dịch vụ hoàn chỉnh: đăng nhập qua Keycloak, đọc và ghi dữ liệu sinh viên trong MariaDB qua Flask API, lưu ảnh đại diện vào MinIO và theo dõi cảnh báo từ Prometheus.

Đăng nhập theo luồng Authorization Code + PKCE: trình duyệt không bao giờ nhận mật khẩu, chỉ nhận access token do Keycloak ký. Tài khoản thử: sv01 (quyền editor) và sv02 (chỉ xem).

1. Chuyển sang Keycloak

Portal tạo code_verifier ngẫu nhiên, gửi kèm code_challenge (SHA-256).

2. Nhận authorization code

Keycloak xác thực người dùng rồi trả code về /portal/.

3. Đổi code lấy token

Portal gửi code + code_verifier; chỉ đúng trình duyệt đã bắt đầu mới đổi được.

4. Gọi API

Mỗi request gửi header Authorization: Bearer; Flask kiểm tra chữ ký, audience, role.

Chưa có ảnh

JPEG hoặc PNG, tối đa 2 MB. App lưu vào bucket profile-pics, trình duyệt đọc lại qua /media/.
