# Logo and icon sources

The pages are served without any CDN, so every image ships inside the `myminicloud-web` image.

| File | Source | Licence |
|---|---|---|
| `html/assets/logos/nginx.svg`, `mariadb.svg`, `keycloak.svg`, `prometheus.svg`, `grafana.svg`, `alertmanager.svg`, `loki.svg`, `alloy.svg`, `docker.svg` | [homarr-labs/dashboard-icons](https://github.com/homarr-labs/dashboard-icons) (the set used by gethomepage.dev) | Apache-2.0 |
| `html/assets/logos/flask.svg`, `minio.svg`, `github.svg` | [Simple Icons](https://simpleicons.org/) | CC0-1.0 |
| `html/assets/logo-cloud*.png`, `favicon-32.png` | Cloud mascot provided by the team (AI-generated image, cropped) | Team asset |

The product logos are trademarks of their owners. They are used only to identify the service each card or link
refers to. Single-colour logos are drawn with a CSS mask (`.mono-logo`) so they follow the light/dark theme.
Services without a logo in either set (BIND9, cAdvisor) show initials instead.
